# 소재공장 — 한글 광고 소재 대량 생성 엔진

## 왜 이것이 범용 AI 로 대체되지 않는가

**먼저 틀렸던 전제를 정정한다.** 이 엔진의 최초 설계 근거는 "이미지 생성
모델이 한글 글리프를 정확히 그리지 못한다"였다. 2026-10-28 에 직접
시험한 결과 **그 전제는 더 이상 사실이 아니다.** 현행 이미지 모델은 긴
한글 문장과 가격 표기까지 정확히 렌더링했고 디자인 품질도 충분했다.

남은 근거는 글리프 품질이 아니라 아래 네 가지다. 실측값으로 뒷받침된다.

| 항목 | 생성 모델에 직접 시키기 | 이 엔진 |
|---|---|---|
| 소재 1장 원가 | 약 63원 | **약 0.16원 (404배)** |
| 200장 원가 | 약 12,700원 | **약 31원** |
| 규격 정확도 | 요청 1080×1920 에 실제 768×1376 | **정확히 1080×1920** |
| 가격·문구 수정 | 전체 재생성, 레이아웃이 바뀐다 | 그 글자만 바뀐다 |
| 브랜드 일관성 | 호출마다 다르다 | 토큰 고정 |
| 각도 전개 | 한 번에 한 장 | 분석 → 각도별 N종 → 규격 전개 |

즉 이 제품이 파는 것은 **글자 품질이 아니라 묶음 처리와 통제력**이다.
검증 조건 중 "수량"과 "행동"(규격 준수), "책임"(표시광고법 가드)이 근거이고,
"충실도"는 글리프가 아니라 **규격·브랜드 일관성** 쪽에서 성립한다.

생성 모델이 더 잘하는 영역도 분명하다. 배경 장면과 연출이다. 그래서
`--scenes` 로 배경만 모델에 맡기고 문구는 코드로 올리는 혼합 경로를 둔다.
장면 1장을 만들어 소재 수십 장에 재사용하면 원가도 유지된다.

## 파이프라인

```
상품 사진 1장
   │
   ├─ 상품 분석 (Gemini vision) ──> 분류·특징·타겟·톤
   ├─ 문구 생성 (Gemini) ────────> 각도별 N종 (글자수 제한 + 광고법 가드)
   ├─ 배경 생성 (선택, Gemini image) ─> 장면 교체. 글자는 넣지 않는다
   └─ 합성 (코드) ───────────────> 규격 × 레이아웃 전개
```

## 한글 타이포 엔진 (`typo.py`)

영문 조판 규칙을 그대로 쓰면 한글 조판이 어색해진다. 이 모듈이 처리하는 것:

- **어절 단위 줄바꿈** — 단어 중간에서 끊지 않는다. 한 어절이 한 줄보다 길 때만
  글자 단위로 쪼갠다.
- **금칙 처리** — 줄 머리에 닫는 괄호·문장부호가 오지 않고, 줄 끝에 여는 괄호가
  남지 않는다.
- **자동 크기 맞춤** — 상자에 들어가는 가장 큰 크기를 위에서부터 찾는다. 광고는
  글자가 클수록 유리하므로 조건을 만족하는 첫 크기에서 멈춘다.
- **대비 자동 판정** — 글자가 놓일 영역의 평균 밝기를 재서 흰/검을 고르고
  그림자를 넣는다.
- **방향성 그라데이션** — 가장자리에 붙는 밴드는 가장자리가 가장 진해야 한다.
  대칭 그라데이션을 깔면 정작 글자가 앉는 쪽이 투명해진다.

## 규격과 레이아웃

| 규격 | 크기 | 비고 |
|---|---|---|
| square | 1080×1080 | 피드 공용 |
| portrait | 1080×1350 | 피드 최대 노출 |
| story | 1080×1920 | 세이프존 상 14% / 하 20% |
| wide | 1200×628 | 배너 |
| thumb | 1000×1000 | 오픈마켓 썸네일 |

레이아웃 4종: `top_band`, `bottom_card`, `center_hero`, `split`.
세로로 긴 story 는 세이프존 때문에 항상 `center_hero` 로 간다.

## 표시광고법 가드

생성 단계와 검출 단계 양쪽에서 막는다. 사후 필터만 두면 모델이 지시를 어겼을 때
그대로 통과한다.

- 프롬프트에 금지 표현을 명시
- 생성 결과에서 금지 표현이 나오면 **그 소재를 버린다**
- 렌더링 시 다시 검사해 경고로 남긴다

금지: 최고, 최상, 유일, 1위, 100%, 완치, 치료, 효과 보장, 부작용 없음, 무조건,
평생, 영구, 공짜, 전액 환불 보장.

## 측정된 원가

| 항목 | 값 |
|---|---|
| 상품 분석 + 문구 6종 | 약 2.8원 |
| 소재 18장 출력 | 추가 비용 0 (로컬 합성) |
| **소재 1장당** | **약 0.16원** |
| AI 배경 장면 1장 (선택) | 약 63원 |

합성이 전부 로컬이라 규격·레이아웃을 늘려도 API 비용이 늘지 않는다.
숏폼 외주가 건당 2~37만원인 시장에서 원가가 1원 미만이다.

## 사용

```bash
sojae doctor                      # 폰트·연결 점검
sojae specs                       # 규격·레이아웃 목록
sojae make 사진.jpg "상품명" \
    --out out --count 8 \
    --specs square portrait story \
    --price "19,900원" --benefit "2+1"
```

`out/manifest.json` 에 상품 분석, 문구, 파일 목록, 원가가 남는다.

## ⚠️ 판매 전 확인

- **폰트 라이선스** — 기본값은 Noto Sans CJK(SIL OFL)로 상업적 이용이 가능하다.
  다른 폰트로 바꿀 때 반드시 라이선스를 확인한다. 소재가 고객에게 팔리므로
  폰트 라이선스가 곧 법적 리스크다.
- **상품 사진 권리** — 고객이 권리를 가진 사진만 받는다.
- **AI 생성 표기** — EU 판매 소재는 AI 생성 표기 의무가 있다(AI Act 제50조).
- **요금표** — `gemini.PRICING` 은 원가 감각용 기본값이다. 공급자 페이지에서
  재확인한다.
