# 전략: 오피스 제품이 아니라 문서 엔진을 판다

> **⚠️ 이 문서의 1순위 판단은 2026-10-28 철회되었다.**
> "AI 가 공문서를 써준다"는 전제가 검증 질문("고객이 범용 AI 로 직접 하면 안 되는
> 이유가 무엇인가")을 통과하지 못했다. 고객은 범용 AI 로 텍스트를 받아 붙여 넣고
> 저장하면 되고, 포맷 변환은 고통이 아니다. 철회 근거와 대체 결정은
> `docs/03-demand-validation.md` 에 있다.
> 아래 내용 중 **아이템 선별 기준**과 **90일 순서**는 여전히 유효하므로 남긴다.
> 이 저장소의 문서 엔진 코드는 폐기하지 않는다 - 다른 제품의 출력 단계에서 재사용한다.

## 진단

오피스 스위트를 완성품으로 파는 길은 막혀 있다.

| 이유 | 내용 |
|---|---|
| 가격 앵커가 0 | Google Docs·LibreOffice·한컴독스 무료. 한컴오피스 가정용도 영구 라이선스 5~9만원대 |
| 범위가 무한 | 워드·PPT 완전 호환은 수백 명이 수십 년 한 일. 1% 깨지면 문서는 버려진다 |
| 전환 동기 부재 | 사람들은 오피스가 싫어서 안 바꾸는 게 아니라, 바꿀 이유가 없어서 안 바꾼다 |

그런데 같은 코드베이스를 다르게 보면 자산의 성격이 달라진다.

> 모든 범용 AI 는 텍스트와 이미지만 출력한다.
> 그런데 한국에서 사람이 제출하는 것은 `.hwp` / `.hwpx` / `.docx` / `.pptx` 다.
> 그 마지막 변환 구간이 비어 있다.

파는 것은 오피스가 아니라 **AI 출력을 제출 가능한 파일로 바꾸는 엔진**이다.

## 아이템 선별 기준

새 아이템은 아래 5개를 모두 통과해야 착수한다.

1. **가격 앵커** — 지금 사람들이 이 일에 월 10만원 또는 건당 50만원 이상 쓰는가
2. **원가 붕괴** — AI·오픈소스로 그 일의 원가가 1/100 이 되었는가
3. **반복성** — 매달 돌아오는 고통인가 (1회성은 구독이 안 된다)
4. **지불 주체** — 사업자인가 (개인은 월 9,900원도 아깝고, 사업자는 인건비보다 싸면 즉시 결제한다)
5. **유통** — 광고 없이 사람이 먼저 찾아오는 검색 키워드가 있는가

소비자용 무료앱이 돈이 안 되는 이유는 4번이다.

## 1순위: 공공 제출문서 자동화

| 항목 | 내용 |
|---|---|
| 제품 | 입찰공고 → 요건 체크리스트 → 제안서·사업계획서 초안을 개방형 문서 포맷으로 출력 |
| 가격 앵커 | 제안서 대행 건당 200~1,000만원, 입찰 컨설팅 월 수백만원 |
| 경쟁 | 해외 RFP 자동화(RFxAI, AutoRFP 등)는 월 $299~1,299 이지만 한국 공공 양식을 다루지 못한다. 국내 전용 서비스는 사실상 공백 |
| 데이터 | 나라장터 입찰공고 OpenAPI 를 공공데이터포털에서 합법 제공 (활용신청 필요) |
| 기존 자산 재활용 | 문서 엔진 그대로 |
| 요금제 | 프리랜서 49,000 / 소기업 199,000 / 팀 590,000 (월) |

**첫 고객이 곧 유통망이다.** 크몽·숨고의 제안서 대행 판매자들은 이미 이 일로 돈을 벌면서 손으로 쓰고 있다.

## 2순위: 레이아웃 보존 문서 번역

모든 번역 도구가 레이아웃 보존을 주장하지만, 실제로는 번역 후 텍스트가 상자를
넘친다. 업계 스스로 "복잡한 서식은 수동 보정이 필요하다"고 인정한다.

해법은 두 가지를 동시에 하는 것이다. 글자 수 상한을 주고 번역시키고,
텍스트 상자와 글꼴 크기를 자동으로 다시 흘린다. 레이아웃 엔진이 있어야
가능하므로 범용 번역기는 따라오기 어렵다.

## 3순위: 착용컷 — 생성기를 버리고 상세페이지로 올린다

착용컷 생성 자체는 이미 포화 상태이고 단가가 장당 $0.75 수준까지 내려갔다.
이미지 장당 경쟁은 들어가면 지는 싸움이다.

올려야 할 포지션은 "사진 1장 → 착용컷 + 상세페이지 + 카피 + 사이즈표 +
스토어 업로드"다. 셀러가 사는 것은 이미지가 아니라 매출이고, 상세페이지는
결국 레이아웃 엔진 문제다. 1순위와 엔진을 공유한다.

## 제외한 것

| 아이템 | 제외 이유 |
|---|---|
| 범용 PDF 편집기 | 포화. 앵커도 이미 월 $20~30 으로 낮다 |
| AI 영상 번역·더빙 | 자본력 경쟁 |
| AI 계약서 생성 | 변호사법 리스크가 수익보다 크다 |
| 소비자용 무료앱 + 광고 | 선별 기준 4번 탈락 |

## 90일 순서

| 기간 | 할 일 | 산출물 |
|---|---|---|
| 1~2주 | 오피스 UI 중단. 엔진을 API 로 분리 | 엔진 API |
| 3~4주 | 나라장터 활용신청 + 공고 → 요건 체크리스트 | 무료 미끼 제품 |
| 5~6주 | 체크리스트 무료 배포, 이메일 수집, 대행 판매자 30명 직접 접촉 | 대기명단 100 |
| 7~10주 | 제안서 초안 유료화. 199,000원 단일 요금제 | 유료고객 10 |
| 11~13주 | 서식 자동 채움 추가, 요금제 3단계 분리 | MRR 300만 |

원칙 세 개.

1. 무료 체크리스트가 미끼다. 미끼 없이는 아무도 오지 않는다.
2. 너무 싸게 받지 않는다. B2B 에서 월 5만원 이하는 못 믿을 물건으로 읽힌다.
3. 마케팅에서 "오피스"라는 말을 뺀다. 그 순간 무료 대체품으로 분류되고 가격이 0 에 수렴한다.
