# 기능 대조표

"워드·한글·파워포인트에서 하던 것 중 무엇이 되고 무엇이 안 되는가"에 대한
솔직한 답입니다. 과장하지 않았습니다.

규모 감각부터: MS 워드는 명령이 1,500개가 넘습니다. 전부 따라가는 건 팀이 몇 년
걸리는 일입니다. 다만 **사람들이 실제로 쓰는 건 그중 5% 남짓**이고, 그 5%는
따라잡을 수 있습니다. 아래 표의 "자주 쓰는지" 열이 그 기준입니다.

## 슬라이드는 "보이는 대로" 그립니다

예전에는 글자만 뽑아 흰 바탕에 늘어놓았습니다. 어두운 배경에 금색 제목인
장표가 흰 바탕에 검은 글씨로 나왔습니다. 지금은 다릅니다.

PPTX 는 보이는 값을 슬라이드에 다 적어두지 않습니다. 제목이 몇 pt 인지,
무슨 색인지는 대개 **레이아웃과 마스터에 적혀 있고 슬라이드는 비워 둡니다.**
그래서 다음 사슬을 끝까지 따라갑니다:

```
런의 rPr → 문단의 defRPr → 도형의 lstStyle
→ 레이아웃의 같은 자리표시자 → 마스터의 같은 자리표시자
→ 마스터의 txStyles → 테마 글꼴
```

색도 마찬가지입니다. `<a:schemeClr val="bg1"/>` 하나를 풀려면
마스터의 `clrMap` 으로 이름을 바꾸고(`bg1` → `dk2`), 테마의 `clrScheme` 에서
실제 값을 찾고, `lumMod` 같은 변환까지 적용해야 합니다.

글자를 고칠 때는 글상자를 **두 번 누르거나** 오른쪽 위 `고치기` 단추를 누르세요.
평소에는 서식 그대로 보여 주고, 누를 때만 편집으로 바뀝니다. 계속 편집 상태로
두면 한 줄 안에 색과 크기가 섞인 장표가 첫 서식 하나로 뭉개져 보입니다.

## 표는 이렇게 씁니다

- **만들기** — 도구막대 `표 ▾` 에서 격자로 크기를 고르거나 `Ctrl+Alt+T`
- **칸 이동** — `Tab` / `Shift+Tab`. 마지막 칸에서 `Tab` 을 누르면 줄이 하나 늘어납니다
- **범위 고르기** — 첫 칸을 누르고 마지막 칸을 `Shift+클릭`
- **합치기 / 나누기** — 범위를 고른 뒤 도구막대의 `셀 합치기`, 되돌릴 땐 `셀 나누기`
- **줄·칸 추가** — 도구막대 또는 `Ctrl+Alt+↑↓←→`
- **칸 색** — 도구막대의 색 단추. 고른 범위 전체에 칠해집니다

커서가 표 안에 있을 때만 표 도구막대가 나타납니다. 표를 쓰지 않을 때는
화면을 차지하지 않고, 쓸 때는 메뉴를 뒤질 필요가 없습니다.

## ⚠️ 표시의 뜻 — 가장 중요한 약속

**"보존됨"은 "열었다 저장해도 사라지지 않는다"는 뜻입니다.**

표·이미지·차트·테마·각주·애니메이션처럼 아직 편집 기능이 없는 것들도, 파일을
열어 글자 하나만 고쳐 저장하면 **원본 그대로 남습니다.** 우리가 해석한 부분만
다시 쓰고 나머지는 바이트를 그대로 복사하기 때문입니다.

문서 편집기에서 제일 무서운 건 기능이 모자란 게 아니라, 열었다 저장했더니 표가
날아가는 것입니다. 그 일이 한 번 생기면 그 프로그램은 두 번 다시 못 씁니다.
그래서 기능을 늘리는 것보다 이 약속을 지키는 쪽에 구조를 맞췄습니다.

## 한글이 만든 진짜 파일로 확인했습니다

한컴오피스 한글이 뱉은 `.hwpx` 세 개(한글 13 빈 문서, 한글 11 정부 기안문 서식
두 개)로 검증했습니다.

- 셋 다 열리고, 글꼴·서식·스타일 표를 전부 읽습니다.
- **손대지 않고 저장하면 모든 XML 파트가 바이트까지 똑같습니다.**
- 한글이 만든 표를 격자로 정확히 읽습니다 (병합된 셀 포함).
- 고쳐서 저장해도 미리보기 이미지 같은 나머지가 그대로 남습니다.

손에 있는 `.hwpx` 로 같은 검사를 돌려볼 수 있습니다:

```bash
npm run verify:real -- 어떤문서.hwpx
```

## 구형 `.hwp` 는 읽기 전용입니다

HWP 5.0 바이너리는 읽기만 합니다. 레코드 트리를 재구성하다 한 군데만 어긋나도
한글이 파일을 거부하기 때문입니다. "저장은 되는데 열리지 않는 파일"은 기능이
없는 것보다 나쁩니다.

대신 열어서 `.hwpx` 나 `.docx` 로 바꾸면 그때부터 편집할 수 있습니다.
화면에 변환 버튼이 바로 나옵니다.
