# 단가와 합법성

## 구독 vs API — 자기 구독비는 줄지 않는다

1M 토큰당 USD:

| 모델 | 입력 | 출력 | 캐시 읽기 |
|---|---|---|---|
| Opus 5.5 | $4.00 | $20.00 | $0.20 |
| Sonnet 5.5 | $2.00 | $10.00 | $0.20 |
| Haiku 5.5 | $0.10 | $0.50 | $0.01 |

코딩 에이전트를 하루 종일 돌리면 세션당 $3 내외, 월 30세션이면 $90 수준이다.
월 $100 구독과 거의 같거나 더 비싸고, 종량제는 청구 상한이 없다.

**결론: 구독은 유지한다. 거기서 아낄 돈은 없다.**

## 돈이 나오는 곳은 범용과 전용의 차이

범용 에이전트는 매 턴 코드베이스를 다시 읽는다. 전용 도구는 그럴 필요가 없다.
같은 모델을 쓰는데도 건당 원가가 수십 배 차이난다.

`gongmun cost` 로 계산한 실측값:

| 작업 | 모델 | 토큰 가정 | 건당 원가 |
|---|---|---|---|
| 요건 체크리스트 | Haiku 5.5 | 입력 40K / 출력 3K | **약 7.6원** |
| 제안서 초안 | Opus 5.5 | 캐시 150K + 신규 8K / 출력 30K | **약 914원** |

요금제 마진:

| 항목 | 금액 |
|---|---|
| 청구 (월 20건) | 199,000원 |
| API 원가 | 18,272원 |
| 마진 | **180,728원 (90.8%)** |

무료 미끼 제품은 건당 7.6원이므로 **1만 건을 뿌려도 76,000원**이다.
무료 배포가 마케팅비로 성립한다.

재현:

```bash
gongmun cost --price 199000 --volume 20
gongmun cost --model claude-haiku-5-5 --cached 0 --fresh 40000 --output 3000
```

## 원가를 누르는 수단

`llm/client.py` 에 구현된 것.

1. **모델 라우팅** (`ROUTES`) — 추출·분류는 Haiku, 최종 생성만 Opus.
   같은 작업에서 Haiku 가 Opus 보다 20배 이상 싸다.
2. **프롬프트 캐싱** — 서식·규정·과거 제안서는 매 호출 동일하다.
   캐시 읽기 단가가 입력의 1/20 이므로 큰 고정 컨텍스트일수록 이득이 크다.
   변하는 내용은 반드시 캐시 구간 **뒤**에 놓는다.
3. **effort 조절** — 추출 단계는 `low`, 작성 단계는 `medium` 이상.
4. **원가 집계** (`Usage`) — 모든 호출이 토큰과 비용을 누적한다.
   요금제를 추측으로 정하지 않는다.

실시간이 필요 없는 야간 일괄 처리에는 Batch API(50% 할인)를 추가로 쓸 수 있다.

## ⚠️ 합법 / 위반의 경계

여기를 틀리면 사업이 아니라 사고가 된다.

| | 합법 | 위반 |
|---|---|---|
| 무엇 | API 로 직접 호출해 내 앱을 만들고 그 앱을 판다 | 소비자 구독 계정을 공유·중계·재판매한다 |
| 왜 | API 는 상업적 재판매가 허용된 제품이다 | 소비자 구독은 개인 사용 전용이다 |

"비싼 것을 싸게"를 계정 공유로 구현하면 안 된다. API 종량제로 구현하면
완전히 정상적인 사업이다.

## 포맷·라이선스 경계

허용:

- **DOCX / PPTX / XLSX** — ECMA-376 / ISO 29500 공개 표준
- **HWPX** — KS X 6101(OWPML) 국가표준
- 오픈소스 엔진 — LibreOffice(MPL/LGPL), PDFium(BSD), pdf.js(Apache)
- "개방형 문서 포맷 호환" 같은 사실 서술

금지:

| 금지 | 이유 |
|---|---|
| 상용 소프트웨어를 서버에 설치해 API 로 중계 | 이용약관·라이선스 위반 |
| 제품명·도메인에 타사 상표 사용 | 상표권 침해. 로고·UI 모방도 포함 |
| AGPL 엔진(Ghostscript, MuPDF)을 SaaS 에 사용 | 소스 공개 의무가 발동한다. PDFium 으로 대체 |
| 바이너리 `.hwp 5.0` 역공학 | 공개 규격인 HWPX 만 사용 |
| 나라장터 비공식 엔드포인트 크롤링 | 공식 OpenAPI 만. 활용신청하고 이용범위를 지킨다 |
| 법률·의료·세무 "자문" | 변호사법 제109조 등. "초안·검색 리포트"로만 포지셔닝 |

생성물에는 "법률 자문이 아니다"를 명시한다 (`llm/requirements.py` 의 유의사항).

## 착용컷 관련 규제

- 실제 인물의 얼굴을 학습·재현하지 않는다. 합성 얼굴만 사용한다.
- 실제 모델을 쓰면 초상권 동의서를 받는다.
- **EU AI Act 제50조가 2026년 8월 2일 발효됐다.** AI 생성 이미지는
  기계판독 마킹(C2PA) 의무, 딥페이크는 고지 의무가 있다.
  → "AI 생성 표기 자동 삽입"을 기능으로 만들어 판다. 규제가 판매 포인트가 된다.
- 국내는 전자상거래법 허위·과장광고 조항. 실물과 다른 과장 피팅에 주의한다.
